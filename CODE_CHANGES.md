# Full-data release

VOC 2012 uses all 10,582 train_aug images and all 1,449 validation images.
COCO 2014 uses all 82,783 training images and all 40,504 validation images.
Each dataset's five experiment variants share complete training, validation and
CAM evaluation lists and the same training schedule.

See [the full-data configuration record](docs/FULL_DATA_CHANGELOG.md) and
`PACKAGE_QA.json` for configuration and verification details. Full-data benchmark
results require training and evaluation and are not included in this release.
